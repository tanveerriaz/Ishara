# Attribution

This project **aggregates and organizes** publicly available Qur’anic resources for study. **None of the primary text is original to the author.** Please credit the upstream sources when reusing the vault or web export.

## Project role

Scripts, vault layout, and web viewer UI are provided for education and exploration. Translations remain under their respective publishers’ terms. Verify important matters of religion against primary scholarship — this is a meaning-graph tool, not a fatwa source.
